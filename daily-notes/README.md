# Daily Learning Notes

**Instructions**: Create a new markdown file for each day. Use the format: `YYYY-MM-DD.md`

Example: `2026-05-29.md`

---

## Template for Daily Notes

```markdown
# Date: [YYYY-MM-DD]

## 📚 Topics Studied Today

- Topic 1
- Topic 2
- Topic 3

## 💻 Code Written

- File/Project name
- What you built/practiced

## 🧮 Problems Solved

- LeetCode Problem #123 - [Problem Name]
- Practice Problem - [Description]

## 💡 Key Learnings

- Learning point 1
- Learning point 2
- Learning point 3

## 🤔 Challenges Faced

- Challenge 1 and how you solved it
- Challenge 2

## ✅ Daily Checklist

- [x] Studied topics
- [x] Wrote code
- [x] Solved problems
- [x] Pushed to GitHub
- [x] Updated tracker

## 📝 Tomorrow's Plan

- What to study tomorrow
- Goals for next day

## 🔗 Useful Links

- Link 1
- Link 2
```
