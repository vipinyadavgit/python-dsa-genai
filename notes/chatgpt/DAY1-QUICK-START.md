## 🆘 Troubleshooting

### "I don't have 2 hours today"
- Minimum: Do 45 min learning + update tracker
- Make up tomorrow with 2.5 hrs
- Consistency > perfection

### "Topic is too hard to understand"
- Ask AI to explain simpler (like I'm 5 years old)
- Watch a YouTube video from resources list
- Move ahead, come back later with fresh mind

### "I'm stuck on a coding problem"
- Add code file as context in VS Code Chat
- Ask: "Debug this code and explain the issue"
- Read error messages carefully
- Google is your friend

### "Lost motivation"
- Read `roadmap-plan.md` section: "Remember Why You Started"
- Look at your GitHub commit streak
- Think about your end goal
- Take a day off if really needed (but not more than 1!)
