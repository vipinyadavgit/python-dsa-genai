Weeks 1-4: Core Java Production Issues
📚 Topics to Learn:
  • Week 1: Stack traces, basic debugging with IDE
  • Week 2: OutOfMemoryError, heap dumps, exception handling
  • Week 3: StackOverflowError, thread dumps, deadlock detection
  • Week 4: JVM monitoring (jps, jstack, jmap), profiling basics
🔬 Practice Exercises:
  • Intentionally create memory leak → detect with jmap
  • Create infinite recursion → analyze with stack trace
  • Create deadlock scenario → detect with jstack
  • Practice reading heap dumps with VisualVM/Eclipse MAT

  • Fill "Core Java Issues" section
