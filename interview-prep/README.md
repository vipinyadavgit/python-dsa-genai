## 🧮 DSA Interview Patterns

### Common Patterns

1. **Two Pointers** - Array problems
2. **Sliding Window** - Substring/subarray problems
3. **Fast & Slow Pointers** - Linked list cycles
4. **Merge Intervals** - Interval problems
5. **Cyclic Sort** - Missing/duplicate numbers
6. **In-place Reversal** - Linked list reversal
7. **BFS/DFS** - Tree/Graph traversal
8. **Top K Elements** - Heap problems
9. **Binary Search** - Sorted array search
10. **Backtracking** - Permutations/combinations
11. **Dynamic Programming** - Optimization problems

### Practice Strategy

- Solve 5-10 problems per pattern
- Focus on understanding, not memorization
- Practice explaining solutions
- Time yourself
- Revisit hard problems

## 📝 Common Interview Questions

1. What is the difference between list and tuple?

4. Difference between `__str__` and `__repr__`
5. How does Python manage memory?
6. What is a generator? Why use it?
7. Explain `*args` and `**kwargs`
8. What is the difference between `is` and `==`?

### Backend Questions

1. What is REST API?
2. Explain HTTP methods (GET, POST, PUT, DELETE)
3. What is authentication vs authorization?
4. What are status codes? (200, 400, 401, 404, 500)
5. What is CORS?
6. Explain JWT tokens
7. What is database indexing?
8. What are ACID properties?

### DSA Questions

1. Reverse a linked list
2. Find two numbers that sum to target
3. Longest substring without repeating characters

### GenAI Questions

## 🎯 Interview Preparation Checklist

### Before Interview

- [ ] Research the company
- [ ] Review job description
- [ ] Practice common questions
- [ ] Prepare questions to ask
- [ ] Test your setup (for virtual)

### During Interview

- [ ] Think out loud
- [ ] Ask clarifying questions
- [ ] Start with brute force, then optimize
- [ ] Test your code
- [ ] Discuss trade-offs

### After Interview

- [ ] Send thank you email
- [ ] Note down questions asked
- [ ] Identify areas to improve
